# 🌐 HTML Fundamentals — Building the Web from Scratch

A structured collection of HTML files documenting the process of learning the language of the web from first principles. Every webpage — no matter how sophisticated — is built on HTML. This repository captures that learning: from basic document structure and text formatting to multimedia embedding, semantic layout, and interactive forms.

## ✨ Project Overview

Before CSS makes things beautiful and JavaScript makes them dynamic, HTML defines what a page *is*. This repo is a hands-on reference built file by file as each concept was introduced during **CSE — Web Technologies** coursework at BRAC University.

It serves as the structural foundation for later work in CSS animations, Flexbox layout, and full-stack web development. Understanding what HTML does on its own — before frameworks abstract it away — is what makes everything else make sense.

## 📁 Files & What They Demonstrate

| File | Concept Practiced |
|---|---|
| `index.html` | Page skeleton: `<!DOCTYPE>`, `<head>`, `<body>`, metadata |
| `format.html` | Text formatting: headings, paragraphs, bold, italic, blockquote |
| `form.html` | User input: `<input>`, `<select>`, `<textarea>`, `<button>`, labels, form structure |
| `table_list.html` | Structured data: `<table>`, `<tr>`, `<td>`, ordered and unordered lists |
| `header&footer.html` | Semantic layout: `<header>`, `<nav>`, `<footer>`, `<main>` |
| `audio.html` | Multimedia: `<audio>` tag with controls, `src`, and fallback content |
| `video.html` | Multimedia: `<video>` tag with autoplay, loop, and `<source>` elements |
| `surah.html` | Personal project: Quranic text rendered with clean semantic HTML structure |
| `Audios/` | Audio assets referenced across the project |

## 💡 Concepts Covered

- HTML5 document structure and semantic elements
- Text content formatting and typography markup
- Forms, input types, and accessible user data collection
- Tables for structured tabular data
- Native multimedia embedding (audio and video without plugins)
- Semantic layout with `<header>`, `<main>`, `<footer>`, `<nav>`

## 🚀 Getting Started

No installation needed. Clone and open any file in a browser:

```bash
git clone https://github.com/chaityrahman154-lgtm/HTML.git
```

Double-click any `.html` file — or drag it into your browser window.
